# Feasibility Study — Block 5 · R7-Ende-zu-Ende (#171, PFLICHT)

Mini-Go-runner with `/v1/embed` (dense) + `/v1/rerank` over the contract §7a
JSON, swapped into the real bench via `AXIOM_PROCESSOR_URL`. Pipeline E2E is
proven; determinism is **inherited** (the mini-runner uses the same engines as
godense/gorerank, each 2×-run byte-equal — the mini-runner itself has no own
2× run); the gold-metric delta is **blocked by a test-DB
source-metadata sync state**, which I report honestly, not around.

## Mini-Go-Runner (commit under `cmd/feasibility/minirunner/`)

`minirunner.main` — a standalone Go HTTP server:
- `/v1/embed`: `onnxruntime_go` BGE-M3 dense encoder (pinned tokenizer + HF
  reindex); returns ≥ `EMBEDDING_SHAPE_MISMATCH` guards compatible with
  `internal/processor/embed_rerank.go`.
- `/v1/rerank`: `onnxruntime_go` bge-reranker-v2-m3 logits → sigmoid; XLM-R pair
  form `[CLS] q [SEP] p [SEP]`; same contract shape as §7a.
- `/v1/health`. **No `/v1/sparse`** (Go sparse output extraction is blocked,
  Block 3) — the ±sparse bench rows are dropped per the issue.

Verified live:
```
curl /v1/embed {"texts":["Öffentlichkeit Straße"]} → dims=1024 model=BAAI/bge-m3
curl /v1/rerank {"query":"Nachhaltigkeit im Unternehmen","texts":[...]} →
   [{index:0,score:0.626},{index:2,score:0.035},{index:1,score:1.6e-5}]   # correct order
```

## Gold-metric delta: BLOCKED by DB sync, not the runner

The bench's P@5/MRR/R@10 depend on hydrating hit `document_id` → book title from
Postgres `zotero_documents`/`processing_chunks` for `isGold` matching. Current
live test-DB state:

```
zotero_documents: 3 rows   (titles "Title V2", "A Book", "A Book" — no real titles)
processing_chunks: 0 rows
processing_chunk_dense_embeddings: 0 rows
OpenSearch axiom-ng-chunks-v1: 35,224 docs
```

The OS index is populated but the **Postgres source metadata is empty/out of
sync**, so `Source.Book` hydration returns no gold titles → gold matching would
report ~0 P@5/MRR/R@10 **for any runner (Python or Go)**. The R7 figures in
`RETRIEVAL_BENCHMARK.md` were produced when the DB held the full library metadata.
**Reproducing the metric delta requires the source-metadata to be synced first**
(a data prerequisite, not a runner limitation).

## R7-delta on the carrier (Nachzug) — CUDA mini-runner swap PROVEN

Carrier measurement (2026-08-17): the Mini-Go-runner runs in the study container
on the carrier **with CUDA-EP** (GPU 0), serving `/v1/embed` (dense) + `/v1/rerank`
bound to 0.0.0.0:8013. The bench runs **locally on the Mac** against the local
OpenSearch (`axiom-ng-chunks-v1`, 35,224 docs) + Postgres, with
`AXIOM_PROCESSOR_URL` connected to the carrier mini-runner over an SSH port-forward
(Mac 127.0.0.1:8013 → carrier 127.0.0.1:8013; a firewall on both sides blocks
direct LAN:port, the SSH tunnel is the robust mechanism).

| config | P@5 | MRR | R@10 | p50 | p95 | errs |
|---|---|---|---|---|---|---|
| dense-only | 0.000 | 0.000 | 0.000 | 76 ms | 309 ms | 0 |
| hybrid (dense+bm25) | 0.000 | 0.000 | 0.000 | 76 ms | 162 ms | 0 |
| hybrid+rerank | 0.000 | 0.000 | 0.000 | **736 ms** | 804 ms | 0 |
| +sparse | 0.000 | 0.000 | 0.000 | 725 ms | 848 ms | 0† |
| +graph | 0.000 | 0.000 | 0.000 | 742 ms | 822 ms | 0† |

† sparse/graph rows fall back to dense-only (mini-runner rejects `include_sparse`
with `SPARSE_UNSUPPORTED`); ±sparse rows are out of scope (Nachzug rule).

**The AXIOM_PROCESSOR_URL swap works end-to-end** (bench local → carrier CUDA
mini-runner → dense embed + rerank; `errs 0`). **CUDA rerank latency = 736 ms/query
vs the earlier CPU 18.9 s — a ≈25× speedup**, the concrete value of the farm's
CUDA column.

**Gold metrics are 0.000** solely because the local Postgres durable source metadata
is empty (`zotero_documents=3`, `processing_chunks=0`, `processing_chunk_dense_embeddings=0`,
`processing_snapshots=0`; verified) while the OS index has 35,224 chunks. The task
premise that the DB is now "full (126 docs / 35,880 chunks)" does **not** hold in
this environment — provisioning (re-ingest/hydrate the durable metadata) is a
prerequisite for a non-zero gold delta, for Python OR Go. The R7 *pipeline* path
(swap, embed, rerank, OpenSearch+DB) is proven; the *gold* numbers await the data.
